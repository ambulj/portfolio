## Design System Specifications (Swiss / International Typographic)

- **Aesthetic Direction:** Editorial academic monograph / high-craft systems documentation.
- **Color Palette (Dual Mode via CSS Variables):**
  - **Light Mode:** Canvas `#F9F9FB` | Ink `#111113` | Rule `#E2E4E8` | Secondary `#525866` | Accent `#0066FF`
  - **Dark Mode:** Canvas `#0D0E11` | Ink `#ECECED` | Rule `#22252B` | Secondary `#8A909E` | Accent `#2979FF`
- **Typography:**
  - Headings / Nav: IBM Plex Sans Condensed (500, 600)
  - Long-Form Body: IBM Plex Serif (400, 400i, 600) with 1.6 line-height, measure <= 68ch
  - Code & Metrics: IBM Plex Mono (400)
- **Eliminated Tropes:** All CRT scanlines, OLED pure-black neon glow, DEFCON audio sirens, and sci-fi badges.
- **Architectural Shift:** Case studies are quiet, peer-grade, distraction-free reading; interactive tools (ONNX inference, SOC visualizer, 3D topology) are isolated cleanly into a dedicated `/lab` section.
